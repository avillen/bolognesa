# Triage labels

Triage skills speak in five canonical roles. Use the label string mapped to each role.

Keep area labels (`music`, `series`, `library`, `settings`) and type labels (`bug`, `enhancement`) alongside one triage label.

| Role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `question` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified; an agent can implement it unattended |
| `ready-for-human` | `ready-for-human` | Needs human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |
